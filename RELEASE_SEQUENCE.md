# Production Release Sequence

1. Provision production infrastructure.
2. Configure DNS and HTTPS.
3. Configure production secrets.
4. Create production database.
5. Run all migrations.
6. Deploy API.
7. Deploy Web.
8. Deploy Admin.
9. Deploy Author Portal.
10. Configure storage/CDN.
11. Configure payment gateway and verified webhooks.
12. Run production smoke tests.
13. Enable monitoring/alerts.
14. Build and submit Android AAB.
15. Build and submit iOS release.
16. Gradually open production traffic.
