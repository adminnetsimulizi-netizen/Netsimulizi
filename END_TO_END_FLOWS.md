# End-to-End Flows
Author: Admin creates account -> author submits -> declaration -> admin approval -> publish.
Reader: language -> browse -> story -> chapter -> purchase/unlock -> read -> library/progress.
Payment: gateway -> verified webhook -> ledger -> entitlement.
Revenue: normal 70/30; promoted 50/50.
Withdraw: balance >= TSh 50,000 -> request -> processing -> paid.
Copyright: complaint -> evidence -> review -> action -> audit.
