# Net Simulizi Product Specification

## Entry
Language selection first: English / Kiswahili.

## Reader
Home, Discover, Search, Categories, Story Details, Reader, Library, Wallet, Profile, Notifications.

## Reader protection
Disable ordinary text selection/copy/print where technically possible; authenticated APIs; encrypted offline content; dynamic account watermark; mobile screenshot/screen-recording controls where supported by OS. No browser can guarantee 100% screenshot prevention.

## Author
No public author registration. Admin creates author account. Author uses a private submission portal. Every story requires an ownership/originality declaration before submission.

## Approval
Draft -> Submitted -> Pending Review -> Approved -> Published
or Rejected -> Revision -> Resubmitted.

## Revenue
Standard: 70% author / 30% platform.
Promoted story: 50% author / 50% platform.
Withdraw button is available only when available balance >= TSh 50,000.

## Promotion
Author requests promotion; admin approves/schedules; promoted sales use 50/50 revenue split.

## Copyright
Store declaration, timestamp, author, story version and audit trail. Include complaint/takedown workflow. False ownership claims can trigger removal, suspension and withholding of unpaid earnings according to the Author Agreement/Terms.
